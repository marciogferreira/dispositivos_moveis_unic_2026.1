Sequelize + MySQL2

ORM no Node.js

O que é ORM?

ORM (Object Relational Mapping)

  • Mapeia tabelas → objetos
  • Evita escrever SQL manual
  • Facilita manutenção

Sem ORM


SELECT * FROM usuarios WHERE login = 'admin';

Com ORM


User.findOne({ where: { login: 'admin' } });

Sequelize

  • ORM para Node.js
  • Suporta MySQL, Postgres, SQLite
  • Baseado em Promises

Instalação


npm init -y
npm install sequelize mysql2

Conexão com MySQL


const { Sequelize } = require('sequelize');

const sequelize = new Sequelize(
  'banco',
  'root',
  'senha',
  {
    host: 'localhost',
    dialect: 'mysql'
  }
);

Executando SQL direto


const [results] = await sequelize.query(
  "SELECT * FROM usuarios"
);
console.log(results);

Model Usuário


const { DataTypes } = require('sequelize');

const User = sequelize.define('User', {
  nome: DataTypes.STRING,
  login: DataTypes.STRING,
  senha: DataTypes.STRING
});

Criar Tabela


await sequelize.sync();

CREATE


await User.create({
  nome: 'Márcio',
  login: 'marcio',
  senha: '123'
});

READ


const users = await User.findAll();
console.log(users);

UPDATE


await User.update(
  { nome: 'Novo Nome' },
  { where: { id: 1 } }
);

DELETE


await User.destroy({
  where: { id: 1 }
});

Fluxo ORM

Vantagens

  • Produtividade
  • Menos SQL manual
  • Portabilidade de banco

Desvantagens

  • Performance em queries complexas
  • Curva de aprendizado

Conclusão

Sequelize facilita muito o desenvolvimento com banco de dados no Node.js 🚀
